1.1 Dados e Tipagem

Java é estaticamente tipada: toda variável precisa ter seu tipo declarado e esse tipo não muda durante a execução.

Tipos primitivos

short2 bytesInteiros de -32.768 a 32.767short ano = 2024;
int4 bytesInteiros (~ ±2,1 bilhões)int pop = 214000000;

ExemploTipos.java
public class ExemploTipos {
    public static void main(String[] args) {
        int idade = 20;                 // número inteiro
        double altura = 1.75;           // número decimal
        char inicial = 'M';             // um caractere

        System.out.println("Idade: " + idade);
        System.out.println("Altura: " + altura);
        System.out.println("Inicial: " + inicial);
        System.out.println("É estudante? " + estudante);
    }
}

1.2 Variáveis e Constantes

🔧 Variável — valor que PODE mudar

Sintaxe
tipo nomeDaVariavel = valorInicial;

int notaFinal = 85;
notaFinal = 90;   // ✅ pode mudar — é variável
📏
Regras de nomenclatura (camelCase): não começa com número (2nota ❌), sem espaços (minha nota ❌), sem palavra reservada (int int; ❌). Convenção: primeira palavra minúscula, demais com inicial maiúscula (notaFinal ✅).

🔒 Constante — valor FIXO (final)

Sintaxe
final double PI = 3.14159;
final int MAXIMO_TENTATIVAS = 3;
final String NOME_INSTITUICAO = "UniPampa";

PI = 3.14;  // ❌ ERRO de compilação! Constante não muda
💡
Use constante para valores fixos (PI, limite de vagas, taxa de juros). Use variável para tudo que se altera (contador, saldo, nota digitada).

Entrada de dados — Classe Scanner

import java.util.Scanner;   // SEMPRE no topo do arquivo!

public class Leitura {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Digite seu nome: ");
        String nome = teclado.nextLine();        // lê texto inteiro

        System.out.print("Digite sua idade: ");
        int idade = teclado.nextInt();           // lê inteiro

        System.out.print("Digite sua altura: ");
        double altura = teclado.nextDouble();    // lê decimal

        System.out.printf("%nOlá, %s! Você tem %d anos e %.2f m de altura.%n",
                          nome, idade, altura);

        teclado.close();   // boa prática: fechar o Scanner
    }
}
Método do ScannerLê
nextInt()número inteiro
nextDouble()número decimal
next()uma palavra
nextLine()a linha inteira (inclusive espaços)
⚠️
Pegadinha famosa: nextInt() não consome a tecla Enter. Se usar nextInt() e depois nextLine(), este vai "engolir" o Enter vazio. Solução: coloque um teclado.nextLine(); extra depois do nextInt().

import java.util.Scanner;

public class Circulo {
    public static void main(String[] args) {

Logica.java
int idade = 20;
boolean temCarteira = true;

// Pode dirigir? Precisa das DUAS condições
boolean podeDirigir = (idade >= 18) && temCarteira;   // true

// Invertendo com !
boolean descanso = false;

💡
Avaliação de curto-circuito: no &&, se a primeira condição já é falsa, a Java nem avalia a segunda. Ex.: if (denominador != 0 && 10/denominador > 2) — se denominador for 0, a divisão nem acontece. ✅ Seguro!

3.2 if, if-else e else-if

if simples — executa SÓ SE a condição for verdadeira

Sintaxe
if (nota >= 60) {
    System.out.println("Aprovado! 🎉");
}

if-else — escolhe entre DOIS caminhos

Sintaxe
if (numero % 2 == 0) {
    System.out.println("É par");
} else {
    System.out.println("É ímpar");
}

else-if — cadeia de decisões (UM entre vários)

ConceitoNota.java
import java.util.Scanner;

public class ConceitoNota {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);

        System.out.print("Digite a nota (0 a 100): ");
        int nota = teclado.nextInt();

        if (nota >= 90) {
            System.out.println("Conceito A");
        } else if (nota >= 75) {
            System.out.println("Conceito B");
        } else if (nota >= 60) {
            System.out.println("Conceito C");
        } else {
            System.out.println("Reprovado");
        }
        teclado.close();
    }
}
💡
A Java avalia de cima para baixo e para no primeiro if verdadeiro — por isso não precisamos escrever nota >= 75 && nota < 90.
❌
Erros comuns:
if (nota >= 60); ← ponto-e-vírgula "come" o if!
if (nota = 60) ← atribuição em vez de comparação
Sem chaves, só a 1ª linha pertence ao if ⚠️

3.3 while e for

while — repete ENQUANTO a condição for verdadeira

While.java
int contador = 1;
while (contador <= 5) {
    System.out.println("Contador: " + contador);
    contador++;   // ⚠️ sem isso, loop infinito!
}
🔢
3 elementos essenciais: 1️⃣ Inicialização (int contador = 1;) • 2️⃣ Condição de parada (contador <= 5) • 3️⃣ Atualização (contador++)

do-while — executa PELO MENOS UMA VEZ (teste no final)

Menu.java
import java.util.Scanner;

public class Menu {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int opcao;

        do {
            System.out.println("1- Continuar | 0- Sair");
            System.out.print("Opção: ");
            opcao = teclado.nextInt();
        } while (opcao != 0);

        System.out.println("Programa encerrado.");
        teclado.close();
    }
}

for — ideal quando sabemos QUANTAS repetições

For.java
// Conta de 1 até 10
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}

// Contagem regressiva
for (int i = 10; i >= 1; i--) {
    System.out.println(i + "...");
}
System.out.println("Lançar! 🚀");

break e continue

BreakContinue.java
for (int i = 1; i <= 10; i++) {

Laços aninhados — tabuada

Tabuada.java
for (int tabuada = 1; tabuada <= 3; tabuada++) {
    System.out.println("--- Tabuada do " + tabuada + " ---");

while ou for? Use for quando sabe o número de repetições; use while quando depende de uma condição do usuário (ex.: "digite 0 para sair").

import java.util.Scanner;

    }
}

5.1 Vetores (arrays unidimensionais)

Um vetor guarda vários valores do mesmo tipo sob um único nome, acessados por índice.

⚠️
O índice começa em 0! Um vetor de tamanho 5 tem índices 0, 1, 2, 3, 4. Acessar v[5] gera ArrayIndexOutOfBoundsException 💥
Declaracao.java
// Forma 1: criar vazio (valores padrão: 0, 0.0, false)
int[] notas = new int[5];

// Forma 2: criar já preenchido
int[] idades = {18, 22, 19, 25, 20};

// Acessar e modificar (sempre com o índice)
idades[0] = 21;                    // muda o 1º elemento
System.out.println(idades[2]);     // imprime o 3º elemento → 19
System.out.println(idades.length); // tamanho → 5

Percorrendo o vetor

Percorrendo.java
// Com for clássico (quando precisa do índice)
for (int i = 0; i < vetor.length; i++) {
    System.out.println("Posição " + i + ": " + vetor[i]);
}

// Com for-each (quando só precisa do valor)

Algoritmos clássicos com vetores

OperacoesVetor.java
import java.util.Scanner;

public class OperacoesVetor {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        double[] notas = new double[5];

        // 1) PREENCHER
        for (int i = 0; i < notas.length; i++) {
            System.out.print("Nota " + (i + 1) + ": ");
            notas[i] = teclado.nextDouble();
        }

        // 2) SOMA E MÉDIA
        double soma = 0;
        for (int i = 0; i < notas.length; i++) {
            soma += notas[i];
        }
        double media = soma / notas.length;
        System.out.printf("Média: %.2f%n", media);

        // 3) MAIOR VALOR E SUA POSIÇÃO
        double maior = notas[0];
        int posMaior = 0;
        for (int i = 1; i < notas.length; i++) {
            if (notas[i] > maior) {
                maior = notas[i];
                posMaior = i;
            }
        }
        System.out.println("Maior nota: " + maior + " (posição " + posMaior + ")");

        // 4) CONTAGEM com condição
        int acimaDaMedia = 0;
        for (double nota : notas) {
            if (nota > media) {
                acimaDaMedia++;
            }
        }
        System.out.println("Notas acima da média: " + acimaDaMedia);

        teclado.close();
    }
}

int[][] m = {
    {1, 2, 3},

    {7, 8, 9}

for (int i = 0; i < m.length; i++) {          // cada linha

        System.out.print(valor + " ");
    }
    System.out.println();
}

Exemplo completo — soma de linhas e diagonais

AnaliseMatriz.java
public class AnaliseMatriz {
    public static void main(String[] args) {
        int[][] m = {
            {5, 3, 1},
            {9, 7, 2},
            {4, 6, 8}
        };

        // Soma de cada linha
        for (int i = 0; i < m.length; i++) {
            int somaLinha = 0;
            for (int j = 0; j < m[i].length; j++) {
                somaLinha += m[i][j];
            }
            System.out.println("Soma da linha " + i + ": " + somaLinha);
        }

        // Diagonal principal (onde i == j)
        int somaDiagonal = 0;
        for (int i = 0; i < m.length; i++) {
            somaDiagonal += m[i][i];   // m[0][0], m[1][1], m[2][2]
        }
        System.out.println("Diagonal principal: " + somaDiagonal);
    }
}

Exercício 1 — Estatísticas de um vetor

EstatisticasVetor.java
import java.util.Scanner;

public class EstatisticasVetor {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        int[] v = new int[8];

        for (int i = 0; i < v.length; i++) {
            System.out.print("Número " + (i + 1) + ": ");
            v[i] = teclado.nextInt();
        }

        int soma = 0, pares = 0, impares = 0;
        int maior = v[0], menor = v[0];

        for (int i = 0; i < v.length; i++) {
            soma += v[i];
            if (v[i] % 2 == 0) pares++; else impares++;
            if (v[i] > maior) maior = v[i];
            if (v[i] < menor) menor = v[i];
        }

        System.out.println("Soma: " + soma);
        System.out.printf("Média: %.2f%n", (double) soma / v.length);
        System.out.println("Pares: " + pares + " | Ímpares: " + impares);
        System.out.println("Maior: " + maior + " | Menor: " + menor);
        teclado.close();
    }
}

Exercício 2 — Inverter um vetor

InverteVetor.java
public class InverteVetor {
    public static void main(String[] args) {
        int[] v = {1, 2, 3, 4, 5};
        int[] invertido = new int[v.length];

        for (int i = 0; i < v.length; i++) {
            invertido[i] = v[v.length - 1 - i];   // pega de trás para frente
        }

        System.out.print("Original:   ");
        for (int x : v) System.out.print(x + " ");
        System.out.print("\nInvertido:  ");
        for (int x : invertido) System.out.print(x + " ");
    }
}

❌ Top 8 erros que derrubam na prova

🏆
1. 7 / 2 dá 3 (divisão inteira!) → use 7.0 / 2
2. = em vez de == dentro do if
3. Esquecer contador++ no while → loop infinito
4. Índice vai de 0 a length - 1 (acessar v[length] = crash)
5. String compara-se com .equals(), não com ==
6. Esquecer o import java.util.Scanner;
7. nextInt() seguido de nextLine() sem o nextLine() extra
8. Matriz: m.length é linhas, m[i].length é colunas
